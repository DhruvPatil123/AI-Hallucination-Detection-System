API Reference

The AHDS API is a RESTful service that accepts LLM-generated text and returns a structured hallucination verification report. All endpoints use JSON request/response bodies and Bearer token authentication.

Base URL: https://api.nexa-ai.com/v1
p95 latency target: <200ms  |  p99 target: <500ms  |  Uptime SLA: 99.9%
Authentication

All requests must include your API key in the Authorization header as a Bearer token. API keys are scoped per integration and carry configurable rate limits.

Example
Authorization: Bearer nexaai_sk_prod_8f4a2c91d3e7b05f...
Never expose API keys in client-side code or public repositories.

Verify Endpoint

The primary synchronous detection endpoint. Submits an LLM-generated text response and returns a full hallucination verification report within the p95 latency target.

POST /v1/verify
Request Parameters
ParameterTypeRequiredDescription
textstringrequiredThe LLM-generated text to verify. Max 32,000 characters.
domainstringoptionalDomain context: general | medical | legal | financial. Default: general
thresholdfloatoptionalMinimum confidence to include a span in results. Range 0.0–1.0. Default: 0.4
contextstringoptionalOriginal prompt or context provided to the LLM. Improves grounding accuracy.
model_idstringoptionalIdentifier of the source LLM (e.g. gpt-4o). Used in audit logs.
Code Examples
from nexa_ahds import AHDSClient client = AHDSClient(api_key="nexaai_sk_prod_...") result = client.verify( text="Aspirin 1200mg is the standard dose for MI...", domain="medical", threshold=0.4, model_id="gpt-4o" ) print(result.hallucination_score) # 0.82 print(result.risk_level) # "high" for span in result.flagged_spans: print(span.category, span.confidence)
import { AHDSClient } from '@nexa-ai/ahds'; const client = new AHDSClient({ apiKey: 'nexaai_sk_prod_...' }); const result = await client.verify({ text: 'Aspirin 1200mg is the standard dose for MI...', domain: 'medical', threshold: 0.4, modelId: 'gpt-4o', }); console.log(result.hallucinationScore); // 0.82 console.log(result.riskLevel); // "high"
curl -X POST https://api.nexa-ai.com/v1/verify \ -H "Authorization: Bearer nexaai_sk_prod_..." \ -H "Content-Type: application/json" \ -d '{ "text": "Aspirin 1200mg is the standard dose for MI...", "domain": "medical", "threshold": 0.4, "model_id": "gpt-4o" }'
Batch Endpoint

Asynchronous endpoint for high-volume offline processing. Accepts up to 500 records per request. Returns a job_id immediately; poll /v1/batch/{job_id} for results.

POST /v1/batch
ParameterTypeRequiredDescription
recordsarrayrequiredArray of verify request objects. Max 500 items per batch.
webhook_urlstringoptionalURL to POST results to when batch completes. Must be HTTPS.
prioritystringoptionalnormal | high. Enterprise tier only. Default: normal
curl -X POST https://api.nexa-ai.com/v1/batch \ -H "Authorization: Bearer nexaai_sk_prod_..." \ -H "Content-Type: application/json" \ -d '{ "records": [ { "id": "rec_001", "text": "...", "domain": "medical" }, { "id": "rec_002", "text": "...", "domain": "legal" } ], "webhook_url": "https://yourapp.com/webhooks/ahds" }'
Feedback Endpoint

Submit human-validated ground truth labels for flagged spans. Validated feedback is incorporated into the weekly model retraining cycle, improving detection accuracy over time.

POST /v1/feedback
ParameterTypeRequiredDescription
request_idstringrequiredThe UUID from the original /verify response.
span_idintegerrequiredIndex of the flagged span to label.
labelstringrequiredcorrect | incorrect — whether the detection was accurate.
corrected_textstringoptionalThe factually correct version of the flagged text.
Audit Logs

Retrieve paginated audit logs for all flagged outputs. Logs include metadata required for compliance reporting and are retained for 90 days.

GET /v1/logs
ParameterTypeRequiredDescription
fromISO 8601optionalStart of time range. Default: 24 hours ago.
toISO 8601optionalEnd of time range. Default: now.
risk_levelstringoptionalFilter by: low | medium | high | critical
limitintegeroptionalResults per page. Max 1000. Default: 100.
Response Schema

Every /verify response conforms to the following structure:

{ "request_id": "uuid-v4", "hallucination_score": 0.0–1.0, "risk_level": "low | medium | high | critical", "flagged_spans": [ { "span_id": 0, "start": int, "end": int, "text": "string", "category": "factual|citation|logical|numerical|temporal", "confidence": 0.0–1.0, "evidence": "string | null" } ], "processing_time_ms": int, "model_version": "ahds-v1.0.4" }

Hallucination Categories

AHDS classifies flagged spans into five distinct categories, each representing a different failure mode of LLM generation.

Factual

Plausible but incorrect facts — wrong names, dates, entities, or statistics that don't match verified knowledge bases.

Citation

Invented or inaccurate references to papers, URLs, case law, regulations, or named sources that don't exist or don't match their claimed content.

Logical

Self-contradictions or reasoning errors within the same response or conversation context.

Numerical

Incorrect calculations, measurements, dosages, or statistics presented with false precision.

Temporal

Post-cutoff or out-of-scope information presented as current fact, or incorrect time-based claims.
